# DzenPilot

Веб-сервис для авторов Яндекс Дзена: анализ конкурентов, поиск прибыльных тем,
создание статей с помощью ИИ и планирование публикаций.

Интерфейс полностью на русском языке и рассчитан на новичка без технических знаний.

---

## Что умеет сервис

| Раздел | Что делает | Готовность |
|--------|-----------|-----------|
| **Главная** | Показатели проекта, прогресс настройки, блок «Что сделать сейчас», последняя активность | Готово |
| **Конкуренты** | Каналы под наблюдением, разбор публикаций, отчёт ИИ, сравнение до 10 конкурентов | Этап 3 |
| **Поиск тем** | Подбор тем с оценкой 0–100 и объяснением каждой оценки | Этап 4 |
| **Статьи** | Мастер из пяти шагов, генерация текста, версии, чек-лист | Этап 5 |
| **Контент-календарь** | План публикаций, перетаскивание, часовые пояса | Этап 6 |
| **Аналитика** | Просмотры, подписчики, лучшие материалы, импорт CSV | Этап 8 |
| **Интеграции** | Claude, OpenAI, Gemini, канал Дзена, Telegram, webhook | Готово |
| **Настройки** | Проект, модель ИИ, профиль, безопасность | Готово |

Основа сервиса — авторизация, проекты, база данных, интеграции, модуль ИИ и очередь
фоновых задач — работает полностью. Разделы с пометкой «этап N» открываются
по мере разработки, план описан в [docs/ROADMAP.md](docs/ROADMAP.md).

## Быстрый запуск

Нужна только одна программа — **Docker Desktop**. Python, Node.js и PostgreSQL
устанавливать отдельно не требуется, всё поднимется внутри контейнеров.

Скачать: <https://www.docker.com/products/docker-desktop/>

### Шаг 1. Получите код

```bash
git clone https://github.com/joker03r-ai/dzenpilot.git
cd dzenpilot
```

### Шаг 2. Создайте файл настроек

```bash
cp .env.example .env
```

Откройте `.env` любым редактором. Для первого запуска менять ничего не нужно —
значений по умолчанию достаточно. Ключ Claude можно не вписывать: его удобнее
добавить прямо в интерфейсе, в разделе «Интеграции».

### Шаг 3. Запустите

```bash
docker compose up --build
```

Первый запуск занимает 5–10 минут: скачиваются образы и собираются зависимости.
Последующие — меньше минуты.

### Шаг 4. Откройте сервис

| Адрес | Что там |
|-------|---------|
| <http://localhost:3000> | Интерфейс сервиса |
| <http://localhost:8000/docs> | Документация API, где можно всё попробовать |
| <http://localhost:8000/health> | Проверка: работает ли база и Redis |

Вход по тестовым данным:

```
Почта:  demo@dzenpilot.ru
Пароль: demo12345
```

В демо-проекте уже есть конкурент с публикациями, тема с оценкой 84 из 100,
черновик статьи и запись в календаре — чтобы сразу было видно, как всё устроено.

### Остановка

```bash
docker compose down
```

Данные сохраняются. Чтобы удалить и их: `docker compose down -v`.

## Настройка ИИ

Сервис работает с Claude от Anthropic. Ключ добавляется одним из двух способов.

**Способ 1, рекомендуемый.** Откройте раздел «Интеграции» → карточка
«Anthropic Claude» → «Подключить». Ключ зашифруется на сервере и обратно
в браузер не вернётся — вы будете видеть только маску вида `sk-ant-…a1b2`.
Кнопка «Проверить» сразу покажет, работает ли подключение.

**Способ 2.** Впишите ключ в `.env`, строка `ANTHROPIC_API_KEY=`, и перезапустите
сервис. Так ключ будет общим для всех проектов.

Где взять ключ: <https://console.anthropic.com/settings/keys>

Модель меняется в «Настройки» → «Модель ИИ». Доступны Claude, OpenAI, Gemini
и локальные модели через Ollama или LM Studio. Переключение не требует правки кода:
за это отвечает единый модуль `AIProvider`.

## Проверка, что всё работает

```bash
# Состояние контейнеров — все должны быть в статусе running или healthy
docker compose ps

# Тесты backend
docker compose exec backend pytest

# Проверка типов frontend
docker compose exec frontend npm run typecheck

# Журналы, если что-то пошло не так
docker compose logs -f backend
```

Ожидаемый ответ от `http://localhost:8000/health`:

```json
{
  "status": "ok",
  "version": "0.2.0",
  "database": "доступна",
  "redis": "доступен"
}
```

## Работа с базой данных

```bash
# Применить миграции вручную
docker compose exec backend alembic upgrade head

# Создать новую миграцию после изменения моделей
docker compose exec backend alembic revision --autogenerate -m "описание изменения"

# Откатить последнюю миграцию
docker compose exec backend alembic downgrade -1

# Заново создать тестовые данные
docker compose exec backend python -m app.db.seed
```

## Развёртывание на сервере

Полная инструкция: [deploy/README.md](deploy/README.md).

Кратко: коммит в ветку `main` запускает GitHub Actions, тесты проходят на
чистой базе, затем код уезжает на сервер и контейнеры пересобираются.
Перед каждым обновлением автоматически создаётся резервная копия базы.

## Безопасность

Что реализовано:

- Пароли хранятся в виде bcrypt-хеша, восстановить исходный пароль невозможно.
- Токен сессии лежит в httpOnly-cookie — JavaScript его не видит, поэтому
  XSS не позволяет угнать сессию.
- Ключи интеграций шифруются на сервере алгоритмом Fernet и никогда
  не передаются во frontend.
- Все запросы к базе параметризованы, внедрение SQL невозможно.
- Частота запросов ограничена: 120 в минуту на пользователя, 10 на попытки входа.
- Повторная отправка формы защищена заголовком `Idempotency-Key` — дубликаты
  не создаются.
- Значимые действия записываются в журнал `audit_logs`.
- Пользователь может полностью удалить свой аккаунт со всеми данными.

Чего сервис принципиально не делает:

- не обходит капчу и защиту сайтов от автоматического сбора данных;
- не использует чужие cookies и не публикует через чужие аккаунты;
- не собирает закрытые персональные данные;
- **не публикует статьи без вашего подтверждения** — это отдельное действие,
  которое нужно выполнить вручную.

Если показатель невозможно получить законным путём, сервис пишет
«Данные недоступны» или «Требуется ручной импорт» и не выдумывает цифры.
То же правило действует для ИИ: неподтверждённые утверждения помечаются
строкой «Требуется проверка факта», а несуществующие ссылки не придумываются.

## Частые вопросы

**Docker не запускается на Windows.** Включите WSL 2 и виртуализацию в BIOS.
Docker Desktop при установке подскажет, чего не хватает.

**Порт 3000 или 8000 занят.** Измените внешний порт в `docker-compose.yml`,
например `"3001:3000"`, и перезапустите.

**Забыл пароль от демо-аккаунта.** Значения лежат в `.env`, строки
`SEED_USER_EMAIL` и `SEED_USER_PASSWORD`.

**Сборка падает по нехватке памяти.** Дайте Docker Desktop минимум 4 ГБ:
Settings → Resources → Memory.

**Нужно начать с чистой базы.** `docker compose down -v && docker compose up --build`.

## Разработка без Docker

Понадобятся Python 3.12, Node.js 20, PostgreSQL 16 и Redis 7.

```bash
# Backend
cd backend
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # macOS и Linux
pip install -r requirements.txt
alembic upgrade head
python -m app.db.seed
uvicorn app.main:app --reload

# Frontend, в отдельном окне терминала
cd frontend
npm install
npm run dev
```
