# DzenPilot — карта API

Базовый префикс: `/api/v1`. Документация OpenAPI: `http://localhost:8000/docs`.
Аутентификация — JWT в httpOnly-cookie. Ответы с ошибками имеют единый вид:

```json
{ "error": { "code": "not_found", "message": "Проект не найден", "details": null } }
```

Списочные ответы всегда постраничные:

```json
{ "items": [], "total": 0, "page": 1, "size": 20, "pages": 0 }
```

Общие query-параметры списков: `page`, `size`, `search`, `sort` (например `-created_at`),
плюс собственные фильтры каждого раздела.

## Технические требования ко всем маршрутам

* Валидация входа — Pydantic v2, понятные сообщения на русском.
* Пагинация — `page` и `size` (максимум 100).
* Ограничение частоты — 120 запросов в минуту на пользователя, 10 в минуту на `/auth/login`,
  20 в минуту на операции с ИИ.
* Изменяющие запросы принимают заголовок `Idempotency-Key`; повтор с тем же ключом
  возвращает первый результат и не создаёт дубликат.
* Каждое значимое действие пишется в `audit_logs`.
