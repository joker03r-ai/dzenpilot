# DzenPilot — план реализации

Каждый этап заканчивается работающей сборкой: `docker compose up` поднимает проект,
тесты проходят, интерфейс открывается.

## Этап 1. Архитектура — выполнено
* `docs/ARCHITECTURE.md`, `docs/DATABASE.md`, `docs/API.md`, `docs/UI.md`, `docs/ROADMAP.md`.

## Этап 2. Основа проекта — выполнено
* Docker Compose: PostgreSQL, Redis, backend, worker, beat, frontend.
* Полная схема базы (все 20 моделей) и первая миграция Alembic.
* Регистрация, вход, выход, обновление токена, профиль, смена пароля, удаление аккаунта.
* Рабочие пространства, проекты, роли, переключатель проекта.
* Общий дизайн, боковое меню, все восемь разделов, пустые состояния.
* Главная страница с показателями и блоком «Что сделать сейчас».
* Интеграции: сохранение ключей в зашифрованном виде, проверка подключения.
* Модуль AIProvider с реализацией Anthropic Claude.
* Тестовые данные (`seed`), автотесты авторизации и проектов.

**Проверка:** регистрация → создан проект → открывается главная → работает меню →
подключается ключ Claude → тестовый запрос к модели проходит.

## Этап 3. Конкуренты
* Добавление по ссылке и по названию, группы, заметки, редактирование, удаление.
* Хранение публикаций конкурента, ручной ввод и импорт CSV.
* Разбор заголовков: длина, эмоциональность, числа, вопрос, призыв.
* ИИ-анализ конкурента фоновой задачей + сохранение отчёта.
* Сравнение 2–10 конкурентов: таблица, графики, рейтинг.

**Проверка:** конкурент добавлен → публикации импортированы → отчёт получен →
сравнение построено.

## Этап 4. Поиск тем
* Форма поиска со всеми параметрами.
* Формула рейтинга 0–100 из десяти составляющих с объяснением.
* Карточки тем, фильтры, сохранение и скрытие.
* Кнопка «Создать статью» переносит тему в мастер.

**Проверка:** запуск поиска → список тем с оценками → тема сохранена → открыт мастер статьи.

## Этап 5. Генератор статей
* Мастер из пяти шагов, редактирование плана до генерации.
* Генерация текста с пометками «Требуется проверка факта».
* Инструменты улучшения, версии, автосохранение, восстановление.
* Чек-лист перед публикацией.

**Проверка:** тема → структура → текст → правки → версия восстановлена → статус «готова».

## Этап 6. Календарь
* Виды день, неделя, месяц, список; перетаскивание мышью.
* Часовые пояса (Москва по умолчанию, Иркутск, Улан-Удэ, Калининград, Екатеринбург,
  Новосибирск, Владивосток, Берлин, произвольный).
* Копирование, перенос, отмена, повторение, заметки, выбор канала.

**Проверка:** статья добавлена в календарь → перенесена мышью → часовой пояс отображается.

## Этап 7. Публикация
* Модуль Publisher: официальное API, партнёрский сервис, экспорт, копирование,
  файл Markdown/HTML, напоминание.
* Предпроверка, обязательное подтверждение пользователем, защита от дублей.
* Журнал публикаций с ответами сервера и повтором попытки.

**Проверка:** предпроверка → подтверждение → экспорт файла → запись в журнале.

## Этап 8. Аналитика
* Показатели, графики, фильтры периода, сравнение с конкурентами.
* Ручной ввод и импорт CSV, экспорт.

**Проверка:** импорт статистики → графики построены → выгрузка CSV скачана.

## Состояние на 25 июля 2026 года

Этапы с первого по восьмой написаны и отправлены в репозиторий.
Код ни разу не запускался: на машине разработки не поднялся Docker,
поэтому первый запуск ещё предстоит. Ожидаются правки после него.

3. Сервис с бизнес-логикой.
4. Маршруты API + тесты.
5. Клиент и страницы фронтенда.
6. Пустые состояния, подсказки, обработка ошибок.
