# DzenPilot — страницы интерфейса

Весь интерфейс на русском языке. Основной принцип: на каждом экране одна главная кнопка
действия и короткое пояснение «Что здесь можно сделать».

## Общая рамка

* Слева — постоянное боковое меню с переключателем проекта.
* Сверху — заголовок раздела, пояснение и главная кнопка.
* Фон — светло-серый, карточки белые, мягкие тени, скругления 12–16 px.
* Состояния: загрузка (скелетоны), пусто (иллюстрация + объяснение + кнопка), ошибка
  (понятный текст + «Повторить»), успех (всплывающее уведомление).

## Разделы меню

| # | Раздел | Путь | Главная кнопка |

| 1 | Главная | `/dashboard` | Создать новую статью |

## 1. Главная — `/dashboard`

* Приветственный блок: «Ваш центр управления контентом Дзена», имя пользователя,
  общий прогресс настройки сервиса в процентах.
* Четыре карточки-показателя: конкуренты, найденные темы, созданные статьи,
  запланированные публикации.
* Блок «Что сделать сейчас»: пять шагов (добавить конкурентов → найти тему →
  создать статью → подключить канал → запланировать публикацию). У каждого шага —
  объяснение, статус, прогресс и кнопка перехода.
* Последняя активность: перспективные темы, новые статьи, публикации конкурентов,
  ошибки публикации, запланированные материалы.
* Главная кнопка: «Создать новую статью».

## 2. Конкуренты — `/competitors`

* Список карточками или таблицей, фильтр по группе и тематике, поиск.
* Кнопки: «Добавить конкурента», «Импорт CSV», «Сравнить выбранных».
* Карточка конкурента `/competitors/[id]`: показатели, публикации, ИИ-отчёт, заметки.
  Недоступные показатели отображаются как «Данные недоступны».
* Сравнение `/competitors/compare`: таблица 2–10 конкурентов, графики, рейтинг.

## 3. Поиск тем — `/topics`

* Форма поиска: ниша, аудитория, регион, формат, период, запрещённые темы,
  уровень конкуренции, цель.
* Результат — карточки тем с оценкой 0–100 и объяснением оценки.
* Кнопки на карточке: «Создать статью», «Добавить в план», «Сохранить тему», «Скрыть тему».
* Карточка темы `/topics/[id]`: полный разбор, заголовки, вопросы читателей,
  идеи серии, монетизация, риски, источники.

## 4. Статьи — `/articles`

* Библиотека с вкладками по статусам: черновик, на проверке, готова, запланирована,
  опубликована, ошибка публикации, архив.
* Мастер создания `/articles/new` — пять шагов:
  1. Основные данные.
  2. Структура (10 заголовков, лид, план, тезисы, заключение, призыв).
  3. Генерация статьи.
  4. Улучшение (сократить, расширить, проще, экспертнее, тон, примеры, повторы,
     читаемость, непроверенные утверждения, промты для изображений).
  5. Проверка перед публикацией — чек-лист.
* Редактор `/articles/[id]`: текст, автосохранение, история версий, восстановление.

## 5. Контент-календарь — `/calendar`

* Виды: день, неделя, месяц, список.
* Перетаскивание статей мышью, смена даты и времени, копирование, перенос, отмена.
* Выбор канала, часового пояса, повторения, заметки.
* Часовой пояс по умолчанию — «Москва, UTC+3», рядом всегда виден выбранный пояс.

## 6. Аналитика — `/analytics`

* Переключатель периода: 7, 30, 90 дней, произвольный.
* Показатели, графики динамики, лучшие статьи, темы и заголовки,
  результат по дням недели и времени публикации, сравнение с конкурентами.
* Ручной ввод и импорт CSV, если автоматических данных нет.

## 7. Интеграции — `/integrations`

* Карточки подключений: Claude, OpenAI, Gemini, Яндекс Метрика, Telegram, Email,
  Webhook, CSV, хранилище изображений, канал Дзена.
* У каждой — статус, кнопка «Подключить» или «Проверить».
* Ключи вводятся один раз и далее показываются маской.

## 8. Настройки — `/settings`

* Вкладки: профиль, проект, стиль текста и аудитория, модель ИИ, безопасность,
  удаление данных.
